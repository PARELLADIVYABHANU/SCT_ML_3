SVM Cats vs Dogs Classification
Overview

This project uses Support Vector Machine (SVM), a supervised machine learning algorithm, to classify images of cats and dogs. Images are preprocessed, resized, converted into feature vectors, and then used to train an SVM model for binary image classification.

Features
Image preprocessing using OpenCV
Cat and Dog image classification
Support Vector Machine (SVM) model training
Model evaluation with accuracy score and classification report
Visualization of sample predictions
Technologies Used
Python
OpenCV
NumPy
Matplotlib
Scikit-learn
